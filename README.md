## 🌟 Overview

Every year, thousands of startup ideas fail—not because the ideas are bad, but because founders lack structured validation, technical planning, market research, and strategic direction.

**Launch Lens** is an AI-powered Startup Intelligence Platform that transforms a simple startup idea into a comprehensive, investor-ready business blueprint.

Instead of switching between multiple tools for market research, competitor analysis, technical architecture, branding, and planning, Launch Lens brings everything together in one intelligent workspace.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/HarshiniChebrolu/Launch-Lens.git
```

Install dependencies

```bash
npm install
```

Create a `.env.local`

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
GEMINI_API_KEY=
TAVILY_API_KEY=
```

Run locally

```bash
npm run dev
```
