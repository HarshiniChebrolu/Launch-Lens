# 🌟 Overview

Every year, thousands of startup ideas fail—not because the ideas are bad, but because founders lack structured validation, technical planning, market research, and strategic direction.

**Launch Lens** is an AI-powered Startup Intelligence Platform that transforms a simple startup idea into a comprehensive, investor-ready business blueprint.

Instead of switching between multiple tools for market research, competitor analysis, technical architecture, branding, and planning, Launch Lens brings everything together in one intelligent workspace.

# 🔑 API Configuration

Launch Lens requires the following APIs to function correctly.

---

## 🤖 Google Gemini API

Used for

- AI Startup Analysis
- Executive Summary
- Technical Blueprint
- AI Copilot
- Branding
- Business Strategy
- Investor Insights
- Pitch Generation

### Get your API Key

1. Visit https://aistudio.google.com/app/apikey
2. Sign in using your Google account.
3. Click **Create API Key**.
4. Copy the generated key.

Add it to

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

---

## 🔍 Tavily Search API

Used for

- Live Market Research
- Competitor Discovery
- Research Paper Discovery

### Get your API Key

1. Visit https://app.tavily.com
2. Create a free account.
3. Open Dashboard.
4. Copy your API Key.

Add it to

```env
TAVILY_API_KEY=YOUR_TAVILY_API_KEY
```

---

## 🗄 Supabase

Used for

- Authentication
- Database
- Report Storage

### Create a Project

1. Visit https://supabase.com
2. Create a new project.
3. Open

```
Project Settings → API
```

4. Copy

- Project URL
- Anon Public Key

Add them to

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_PROJECT_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_ANON_KEY
```

---

Create a file named
